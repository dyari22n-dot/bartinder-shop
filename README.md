# Bartinder Shop — پرۆژەی نوێ

پرۆژەی کۆن سڕایەوە؛ ئێستا **Next.js 16 + TypeScript + Tailwind 4** لە سفرەوە.

## دەستپێکردن

```bash
npm run dev
```

[http://localhost:3000](http://localhost:3000) — دەستکاری سەرەکی: `src/app/page.tsx`

## پاشماوەی کۆن

فایلی `.env`ی کۆن (Firebase و هتد) لە بەرامبەر فۆڵدەرەکەدا هەڵگیراوە:

`C:\Users\Dyari\Projects\.env.bartinder-shop.bak`
